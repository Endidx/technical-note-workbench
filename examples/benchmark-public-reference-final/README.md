## 检索与核对

## 评估范围

仅 notes/ 是可见输入，sources.json 与 gold.json 留作核对。f01、f03、f04、f06、f07 提供父调用与后来公开的决定，共三条 edit、两条 keep。f02、f05、f08 只呈现父代码及其用途，均为 ask。后者的提交正文和实际改动均没有进入笔记。标记为 ask 仅说明这些给定材料不足以决定策略。八条记录中三项明确数值恰好均为 10，不能单凭此集验证任意数值生成。
