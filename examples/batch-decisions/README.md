# OneHotEncoder 本地配置回放

14 篇自行编写的 Markdown 笔记使用同一对版本资料，即相邻目录 `batch-upgrade/sources` 中的 scikit-learn 1.1.3 和 1.4.2。每篇笔记在实现配置解析之前已有预期决策。编辑样例同时指定唯一允许修改的文字，追问样例则指定需要点名的配置或参数。样例由本轮开发者编写，属于定向回归集。没有使用这些结果估算真实用户笔记的命中率。

| 指标 | 当前实现 |
| --- | ---: |
| 决策类型、整篇提案和追问关键词均正确 | 14/14 |
| 需要修改且生成完全相同的预期提案 | 4/4 |
| 给出错误提案的笔记数 | 0 |

[输入与标签](cases.json)记录每篇笔记、参考动作和需要核验的文字。[逐题结果](results.json)附有样例和分析器文件的 SHA-256。下面的命令为每篇笔记单独启动当前源码的批量调查命令，任何一篇未达到预期都会返回非零状态。

```sh
python3 scripts/evaluate_batch_decisions.py --check
```

当前支持调用内的字典字面量，以及同一 Python 代码块中紧邻调用、只有一个使用方的字典赋值。值可以是比较表达式或函数调用，整个提案只改键名。函数局部变量和带类型标注的赋值也能核对。若有动态键、额外展开、共享读者、重复目标键，或定义与消费分处不同代码块，则需要补充证据。对外部配置的追问会提示用户在草稿中补足具体定义，然后重新调查。
