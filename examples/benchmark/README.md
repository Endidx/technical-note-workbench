# KMeans 默认参数迁移评测集

本目录收录 12 篇原创中文示例笔记及其预期审阅动作。技术事实来自 scikit-learn 的版本文档。笔记里的团队、项目和作者意图均为构造的评测场景。所有笔记都围绕同一项 API 变更，适合检查实现能否区分不同上下文。它们只覆盖一个库的一个变更，不能据此估计在其他技术文档上的表现。

## 版本依据

scikit-learn 1.1.3 的 KMeans 默认使用十次初始化。在 1.4.2 中，默认值为 `'auto'`，实际次数取决于 `init`。使用默认的 `'k-means++'` 时为一次，使用 `'random'` 时为十次。显式传入整数 `n_init` 会指定次数。随机种子控制随机过程，与初始化次数分别设置。[1.1.3 官方 API](https://scikit-learn.org/1.1/modules/generated/sklearn.cluster.KMeans.html) · [1.4.2 官方 API](https://scikit-learn.org/1.4/modules/generated/sklearn.cluster.KMeans.html)

## 逐篇标注

每项样例有一份独立的 UTF-8 Markdown 输入。`gold.json` 的 `note` 相对于本目录；`expected` 是应采取的动作，`reason` 给出可供复核的理由。评测实现只应读取笔记和全体样例共用的版本资料，答案及理由由评分步骤使用。本批为按官方语义编写的参考标签，尚无独立人工双人复核。

| 动作 | 判定标准 | 数量 |
| --- | --- | ---: |
| edit | 迁移后的实际次数违背文中明确要求，当前调用有确定的局部修改。 | 4 |
| keep | 当前代码已满足该条笔记的使用意图，或该段仍属于旧环境。 | 5 |
| ask | 需要询问目标、化解用途冲突或取得外部配置，当前证据不足以改写。 | 3 |

固定行为样例包含显式次数、随机初始化、固定版本、历史归档与主动采用新版默认。需要改写的调用覆盖裸构造、导入别名、多行全限定调用，以及容易与次数混淆的随机种子。追问样例分别缺少迁移目标、运行时配置，或存在相互冲突的保真与速度要求。文件标识没有编码答案类别。用这些公开样例调过规则后，应将它们列为回归集；新的泛化评估应另外保留未经调参的样本。
